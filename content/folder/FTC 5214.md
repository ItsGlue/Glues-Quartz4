The goal of this project was to build a competition robot that is able to pick up cubes and score them by placing them into baskets (found in corners) or clipping them onto the bars (AKA "submersible")

For the drivetrain, we used mecanum drive to allow strafing. This allowed the robot to be more easily maneuvered and minimized the need for rotation. The robot was operated with two game controllers, so movement was binded to the left and right joystick for one of them (the other controller was mainly used to control the arm, elevator, and intake mechanism)
<div align="center" style="font-size: 1.3rem;"> * * * </div>
The code for mecanum drive is surprisingly simple:

```
@Override
public void loop() {
    double leftStickY  = -gamepad1.left_stick_y;
    double rightStickY = -gamepad1.right_stick_y;
    double strafe      =  gamepad1.left_stick_x;
    double rotate      =  gamepad1.right_stick_x;

    double frontLeftPower  = leftStickY  + strafe + rotate;
    double backLeftPower   = leftStickY  - strafe + rotate;
    double frontRightPower = rightStickY - strafe - rotate;
    double backRightPower  = rightStickY + strafe - rotate;

    double maxPower = Math.max(1.0, Math.abs(frontLeftPower));
    maxPower = Math.max(maxPower, Math.abs(backLeftPower));
    maxPower = Math.max(maxPower, Math.abs(frontRightPower));
    maxPower = Math.max(maxPower, Math.abs(backRightPower));

    frontLeftPower  /= maxPower;
    backLeftPower   /= maxPower;
    frontRightPower /= maxPower;
    backRightPower  /= maxPower;

    frontLeftMotor.setPower(frontLeftPower);
    backLeftMotor.setPower(backLeftPower);
    frontRightMotor.setPower(frontRightPower);
    backRightMotor.setPower(backRightPower);
}
```
A total of 7 servos were used. The arm and wheel outtake used 2 servos each while the claw intake and extension used the remaining 3. The idea was to be able to use the wheel outtake early to score specimen (game piece + clip) onto the submersible and use the claw intake to reach samples that were located in the center. Additionally we built an elevator driven by 12V DC motors that would allow us to score points into the basket if our teammate was already scoring specimens onto the bar (the bar could fit maybe 10 clips at most so it would be a waste for multiple robots to all score clips). The adaptability of our robot was definitely its most standout feature as most other teams would only focus on one scoring strategy.

Since FTC is approx 10x smaller than FRC, there is a lot less need for vision and odometry. However, this does not mean sensors are completely unnecessary. Implementation of a color sensor allowed us to detect the color of the game piece before it was picked up (there are red, blue, yellow rectangles and you have to score the one of your team color). The color sensor also allowed us to detect the game piece itself as the floor was gray compared to the saturated hues of the rectangles. 

```
@Override
public void runOpMode() throws InterruptedException {
    colorSensor = hardwareMap.get(ColorSensor.class, "sensor_color");

    waitForStart();

    while (opModeIsActive()) {
        int red   = colorSensor.red();
        int green = colorSensor.green();
        int blue  = colorSensor.blue();

        String detectedColor = detectColor(red, green, blue);

        telemetry.addData("Color Detected", detectedColor);
        telemetry.addData("Red",   red);
        telemetry.addData("Green", green);
        telemetry.addData("Blue",  blue);
        telemetry.update();
    }
}

private String detectColor(int red, int green, int blue) {
    if (red > blue && red > green && red > 100)       return "Red";
    if (blue > red && blue > green && blue > 100)     return "Blue";
    if (red > 100  && green > 100  && blue < 100)     return "Yellow";
    return "None";
    }
}
```
